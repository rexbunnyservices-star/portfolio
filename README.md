# Portfolio

Personal portfolio of **Anass** — Web Development, AI & Automation.

Built with [Astro](https://astro.build) and deployed on Cloudflare Pages.

## Sections

- **Hero** — intro + key stats
- **Services** — web dev, AI agents, workflow automation, generative AI, email
- **Showcase Projects** — Rex Bunny Services platform, MY Company AI agents, ComfyUI pipelines
- **Case Study** — automated lead generation & outreach pipeline (n8n · PocketBase · Ollama · Maileroo)
- **Tech Arsenal** — tools across frontend, backend, automation, AI, creative AI, email
- **Contact** — CTA + links

## Commands

| Command | Action |
|---|---|
| `npm install` | Install dependencies |
| `npm run dev` | Start local dev server at `localhost:4321` |
| `npm run build` | Build static site to `dist/` |
| `npm run preview` | Preview the production build locally |

## Deploy

Pushed to GitHub → auto-deploys to Cloudflare Pages (build: `npm run build`, output: `dist`).

Live at <https://rexbunnyservices-star.pages.dev>
